# Changelog

## [1.0.0] - 2025-12-19

### Added
- **Authoring Studio**: A comprehensive wizard-based interface for creating Skills, Competencies, Concepts, and Tools.
- **Library Explorer**: A searchable interface for browsing the "Cognitive Library" with sorting and filtering.
- **Cognitive Visuals**: Dynamic SVG visualization of the Cognitive Coding concept on the homepage.
- **Cognitive Programming Schema**: Standardization of "Schema Standards" to "Cognitive Programming Schema".
- **Validation Engine**: Built-in validation for Cognitive Markdown, checking structural integrity and references.
- **Remote Repository Support**: Ability to clone and reference entities from remote GitHub repositories.
- **Import/Export**: Functionality to export projects as ZIP archives and import them back into the Studio.

### Changed
- **Branding**: Renamed to "The Cognitive Library for AI".
- **Terminology**: Unified terms (e.g., "Open Studio" -> "Authoring Studio", "Discovery Portal" -> "Library Explorer").
- **UI/UX**: Extensive Material UI theming updates, including a cohesive color scheme and responsive layout.
- **Architecture**: Migrated to a static-friendly structure using client-side context for the Studio to support various deployment targets.

### Fixed
- **Bugs**: Resolved various build issues, type safety errors, and deprecated component usages (e.g., MUI Grid v2).
